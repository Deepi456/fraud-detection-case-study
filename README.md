# Proactive Fraud Detection Model

## Overview
This project focuses on building a machine learning model to proactively detect fraudulent financial transactions using large-scale transaction data.

## Project Type
Academic / Internship Assignment Case Study (In Progress)

## Key Tasks
- Data cleaning and preprocessing
- Feature engineering
- Handling class imbalance
- Fraud detection using machine learning
- Model evaluation and interpretation
- Business-driven fraud prevention recommendations

## Tools & Technologies
- Python
- Pandas, NumPy
- Scikit-learn
- Jupyter Notebook

## Model
A Random Forest classifier was used due to its robustness and ability to handle non-linear patterns and imbalanced data.

## Evaluation Metrics
- Recall
- Precision
- F1-score
- ROC–AUC

## Note
The dataset is not included in this repository due to size constraints.
This project was completed as part of an academic/internship assignment.
